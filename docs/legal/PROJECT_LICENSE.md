# PURSUE OS — Project License (Apache-2.0)

> **Source:** PURSUE OS master handoff (authoritative). Restored 2026-08-09.
> **Category:** A — Locked license decision.

## Decision

PURSUE OS is released under the **Apache License 2.0**.

## Reason (from handoff)

- Strong open-source adoption.
- Lower copyleft friction than GPLv3.
- Good compatibility for researchers, companies and other users.
- Explicit patent grant.
- Keeps the code open-source without requiring all derivatives to use GPL.
- Better fit for P4inz's goal of growing the project and brand.
- Branding/trademark protection is handled separately from the software license.

## Scope

- Apache-2.0 applies to **PURSUE's own code**.
- Third-party software distributed with PURSUE may have separate licenses; keep third-party licensing separate from PURSUE's Apache-2.0.
- LICENSE contains the full Apache-2.0 text — do not shorten it.
