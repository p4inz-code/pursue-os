# PURSUE OS — Tool Policy

> **Source:** PURSUE OS master handoff (authoritative). Restored 2026-08-09.
> **Category:** A — Authoritative tool policy.

## Policy

1. **Curate, don't dump.** Initial defaults are ~5–7 useful tools per use case; not every available OSINT tool is installed by default.
2. **Integrate before reinventing.** Use mature existing tools where appropriate; build official tools only where necessary.
3. **Modular.** Tools plug into the investigation platform via the modular/plugin architecture.
4. **Support major frameworks.** The investigation environment should support the frameworks investigators actually use.
5. **User responsibility for hardware.** Hardware-specific limitations remain the user's responsibility.
6. **User-extensible.** Users can install more tools; V2 adds stronger module distribution.

## Implementation-Defined

Tool selection, packaging, and integration mechanics are implementation-defined (Category B), locked during the tooling phases.
