# PURSUE OS — Design Language

> **Source:** PURSUE OS master handoff (authoritative) for direction; specifics implementation-defined. Restored 2026-08-09.
> **Category:** A (direction) / B (specifics).

## Locked Direction

PURSUE may have Kali-like power and investigation depth, but presentation and UX follow the broader PURSUE philosophy:

- **clean**
- **modern**
- **professional**
- **configurable**
- **not intimidating**
- **not cyberpunk**
- **not a green-terminal aesthetic**
- **not excessive hacker imagery**

The UI must not create a **prison-like feeling**.

## UX Principles (locked)

- Simple by default; advanced settings for experienced users (PowerToys-style optional customization).
- User-choice oriented.
- The investigation environment should feel like a complete, professional workstation.
- Terminal: strong UX, syntax highlighting, error highlighting, powerful, configurable, approachable.
- Browser: secure, configurable, understandable network state.

## Implementation-Defined

Concrete palettes, typography, component style, and iconography are implementation-defined (Category B), locked during the UI phases. No mockups are produced before the core exists.
