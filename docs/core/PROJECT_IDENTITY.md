## Purpose

PURSUE OS is an investigation-focused Linux operating system: a dedicated operating environment for investigators covering OSINT, digital investigations, DFIR, secure research, intelligence gathering, evidence-driven workflows and related investigation tasks.

## Philosophy

**One operating system for the investigation workflow.** Investigation is treated as a workflow, not a collection of tools.

## Identity Attributes

Powerful, secure, customizable, professional, approachable, investigator-focused, privacy-oriented, reliable, modular, extensible.

## Presentation

Clean, modern, professional, configurable, not intimidating. Not cyberpunk, not a green-terminal aesthetic, not excessive hacker imagery. The UI must not create a prison-like feeling.
