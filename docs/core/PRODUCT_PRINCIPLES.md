# PURSUE OS — Product Principles

> **Source:** PURSUE OS master handoff (authoritative). Restored 2026-08-09.
> **Category:** A — Authoritative project decisions.

1. **Investigation is a workflow, not a tool collection.** PURSUE treats the investigation domain broadly and integrates tools into one coherent environment.

2. **Evidence is the source of truth.** Evidence integrity and provenance are foundational. AI must never silently alter evidence. AI never becomes the source of truth.

3. **User control.** PURSUE is user-choice oriented. Network state is understandable; Tor is not forced on every request; AI is optional and can be disabled; the browser and terminal remain investigator-controlled.

4. **Strong secure defaults, further configuration available.** "S-class" by default; advanced settings exist for experienced users without overwhelming normal mode. PURSUE never pretends a user is invulnerable.

5. **Simple by default, powerful when needed.** Default UX stays simple; advanced customization (PowerToys-style optional) is available for experienced users.

6. **Curate, don't dump.** Initial default tools are curated (~5–7 per use case), not every available tool. Users can install more.

7. **Integrate before reinventing.** Integrate existing mature tools where appropriate; provide official tools only where necessary; support major frameworks.

8. **Modularity and extensibility.** A strong plugin foundation in V1 so V2 does not require rebuilding.

9. **AI is an assistant only.** AI may summarize, explain, organize, navigate, interpret, and recommend — never manipulate, fabricate, or decide without consent.

10. **Do not overengineer V1.** Build what the locked scope requires, nothing more.

11. **Honest status.** No fake screenshots, badges, downloads, ISO links, benchmark/stability/user-count/completion claims until they actually exist.

12. **Correctness over rushing.** Plan, lock, build, audit, repair, validate each phase, and never skip tests.
