# PURSUE OS — Four Pillars

> **Source:** PURSUE OS master handoff (authoritative). Restored 2026-08-09.
> **Category:** A — Authoritative project decisions.

> **Distillation note:** The master handoff does not name a literal "four pillars" set. The four pillars below are distilled from the dominant locked themes of the handoff, each cited to the handoff statements they rest on. They are a faithful summary, not a new decision.

## Pillar 1 — One Operating System for the Investigation Workflow

*Handoff basis: "One operating system for the investigation workflow." / "The project should treat investigation as a workflow, not simply a collection of tools."*

PURSUE is a coherent investigation environment — research, collect, analyze, connect, preserve, report — not an assembly of unrelated tools.

## Pillar 2 — Evidence Is the Immutable Source of Truth

*Handoff basis: "Evidence is always the source of truth." / "Evidence integrity and provenance are foundational." / "AI must never silently alter evidence."*

Everything in PURSUE — cases, timelines, reports, AI assistance — is anchored to evidence with verifiable integrity and provenance. AI remains an assistant and can never alter or become the source of truth.

## Pillar 3 — Security-First with Strong Defaults

*Handoff basis: "Security is a first-class concern." / "strong default security … 'S-class' by default, with further configuration available" / "Do not pretend that the OS makes a user invulnerable."*

Privilege separation, secure storage, evidence integrity, network boundaries, Tor isolation, plugin isolation, AI boundaries, update security, package integrity, case isolation, secure defaults. Strong by default; no invulnerability claims.

## Pillar 4 — Modularity and Extensibility

*Handoff basis: "modular … extensible" / "The plugin foundation must be designed correctly now so V2 doesn't require rebuilding everything." / "integrate existing tools where appropriate … avoid reinventing mature tools."*

A strong plugin foundation, curated modular tooling, and user-choice customization keep PURSUE purpose-built yet open to growth (V2 plugin system, official modules, public plugins).
