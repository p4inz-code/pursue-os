# Code of Conduct

## Purpose

PURSUE OS is an open-source project intended to support collaboration between developers, investigators, security researchers, designers, and users.

We expect everyone participating in the project to help maintain a professional and technically constructive environment.

## Expected Behavior

Participants should:

- communicate respectfully
- focus criticism on ideas and implementation
- provide constructive technical feedback
- respect different levels of experience
- protect private and sensitive information
- act professionally in project spaces
- assume good faith while investigating disagreements

## Unacceptable Behavior

The project does not tolerate:

- harassment
- threats
- targeted abuse
- discrimination
- personal attacks
- deliberate disruption
- doxxing or publication of private information
- malicious disclosure of sensitive information
- impersonation of project maintainers
- knowingly introducing malicious code or concealed backdoors

## Security and Investigation Material

Do not publish private investigation data, credentials, personal information, stolen material, or sensitive security research in public project spaces.

Use the security reporting process for vulnerabilities.

## Enforcement

Project maintainers may remove contributions or restrict participation when necessary to protect the project and its community.

Serious or repeated violations may result in temporary or permanent removal from project spaces.

## Reporting

Behavioral concerns may be reported privately to the project maintainer.

Security vulnerabilities must be reported according to [`SECURITY.md`](SECURITY.md), not through public discussion.

## Scope

This code applies to project repositories, issue discussions, pull requests, official community spaces, and other spaces where someone is representing PURSUE OS.
