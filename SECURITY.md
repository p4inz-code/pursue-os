# Security Policy

PURSUE is investigation and security software. Security vulnerabilities
must be handled responsibly.

Do not publicly disclose an unpatched security vulnerability before the
maintainers have had a reasonable opportunity to investigate and
address it.

When reporting a vulnerability, include:

- affected component
- affected version or commit
- reproduction steps
- security impact
- relevant logs or proof of concept where safe to provide

Do not include credentials, private keys, personal data, or unrelated
sensitive information in reports.
